# Contributing

Thanks for helping out. Bug reports, questions and ideas go to the Issues of the repository they belong to; for a pull request, open an issue first if the change is not small.

Commit messages follow [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/): `<type>(<scope>): <description>`, in the imperative mood, in lower case, with no trailing period. The full rules and the development setup for the daemon are in the [dnspatch contributing guide](https://github.com/dnspatch/dnspatch/blob/main/CONTRIBUTING.md).

By taking part you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
