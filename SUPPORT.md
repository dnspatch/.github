# Getting help

- **Questions and setup help:** [Discussions](https://github.com/dnspatch/dnspatch/discussions).
- **Bugs and feature requests:** [Issues](https://github.com/dnspatch/dnspatch/issues/new/choose) in the repository the problem belongs to.
- **Documentation:** <https://dnspatch.github.io/dnspatch/>.
- **Security problems:** do not use public channels, follow the [security policy](SECURITY.md).
